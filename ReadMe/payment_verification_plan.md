# 贷款还款验证方案

## 目标
确保贷款还款记录的准确性、安全性和可验证性，防止财务混乱或用户信任问题。

## 风险
如果缺乏验证机制，可能导致付款记录错误，带来信任和财务风险。

## 建议方案（分阶段）

**第一阶段：手动验证**
- 用户填写银行账号、公司账号、付款金额。
- 可选上传：付款凭证（截图、收据）。
- 管理员手动确认是否匹配预期付款。

**第二阶段：半自动匹配**
- 系统自动尝试匹配金额、日期、目标账号。
- 仍保留人工审核选项。

**第三阶段：全自动化（可选）**
- 接入银行API（如 Plaid 或开放银行接口）。
- 自动拉取交易记录并验证付款。
- 更适合大规模应用，但需合规和配置成本。
