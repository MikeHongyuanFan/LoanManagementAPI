1. Configure the Django settings module:
   ```bash
   export DJANGO_SETTINGS_MODULE=loan_management.settings
   ```

2. Ensure all required dependencies are installed:
   ```bash
   pip install -r requirements.txt
   ```

3. Set up the test database:
   ```bash
   python manage.py migrate --settings=loan_management.settings
   ```

4. Run the tests with the Django test runner:
   ```bash
   python manage.py test Testing.Stage2_InputValidation.document_management.tests
   ```
